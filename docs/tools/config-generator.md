# 配置生成器 {#config-generator-title}

配置生成器已迁移为独立单页应用，使用 Rust 和 Leptos 在浏览器本地运行。

[打开独立配置生成器](/tuic/config-generator/){ .md-button .md-button--primary }

生成 TUIC 服务端与客户端的 TOML、JSON、YAML 配置，支持配对生成、多用户、TLS、SOCKS5 和 TCP/UDP 转发。页面无需文档站框架或后端服务，不保存或上传输入。

使用方式与版本限制见[配置生成器说明](config-generator-reference.md)。
